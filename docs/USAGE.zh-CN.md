# 使用指南

## 在 Reset 前用足剩余额度

临近额度重置时，可以在 Codex 中启动更多任务，使用更大的模型、更高的推理强度或更快的速度。先在 AlmostReset 设好重置后的停止与调整规则，再启动一次性监听；应用检测到额度恢复后，按优先级处理这些高消耗会话。

为重点任务建立靠前的指定会话规则，让它降配置继续；再用条件规则批量停止或调整其他任务。条件规则在触发时重新匹配，可以覆盖监听后新启动的运行中会话。多开会话和提高配置由你在 Codex 中完成。

周期到期与服务商额外提供的重置都按实际额度提升判定。应用按检查间隔轮询，在首次读到提升时开始处理，响应时间受轮询间隔、连接与执行耗时影响。

## 重置与一次性监听

AlmostReset 比较同一账号、同一数据源中各额度窗口的有效已用百分比。只要已用百分比严格下降，就表示剩余额度增加，算作一次重置；不要求达到预计重置时间，也没有最小提升幅度。只有重置时间变化、额度没有增加时不会触发。

点击「启动」后，应用请求新的读数建立基线。此前收集的读数不会触发本轮动作。账号或数据源变化、新出现的额度窗口会各自建立基线；缺失或无效的额度不会当作零。重复和乱序读数被忽略，连接恢复后可继续与上次有效基线比较。

第一次额度提升会先结束本轮等待，再处理规则。多个额度同时提升只执行一轮；零匹配、部分失败或全部失败也不会自动重新监听。需要下一轮时再次点击「启动」。退出或重启应用不会恢复监听，也不会补执行离线期间的动作。

自动轮询只在准备或监听期间运行。待启动或已完成时，可以手动刷新；会话选择和预览入口也会按需刷新。状态下方时间表示最近一次完成用量与会话读取的时刻，精确到秒。设置中重新连接会结束当前等待，开机启动也不会自动启动监听。

临时读取失败时保留上次有效额度，环形图显示「上次读数」，菜单栏百分比前加 `~`；刷新时间不会更新。未监听时自动进行最多两次恢复读取（分别等待 2 秒和 5 秒），监听中按检查间隔继续读取。关闭窗口或菜单栏不会取消正在进行的刷新。缓存仅用于显示，不会提交给重置检测或触发会话操作。

## 匹配范围与优先级

「指定会话」选择运行中或最近 30 分钟活跃的会话。标题搜索和深度链接遵循同一范围。保存的是会话 ID，执行前会重新检查其状态与活跃时间。

「条件筛选」在重置时匹配运行中的会话，因此之后新启动、满足条件的会话也可能命中。可设置模型、推理强度、速度和状态；每行等于条件可以选择多个值。

从第二行开始选择「且／或」，**且优先于或**。例如 `模型 = 6-astra 或 速度 = fast 且 推理强度 > high` 表示匹配所有 6-astra 会话，以及同时满足快速和高于 high 的会话。推理强度比较顺序为：

```text
none < minimal < low < medium < high < xhigh < max < ultra
```

规则从上到下匹配，每个会话只由第一条命中的启用规则处理。即使该规则的动作暂时不可执行，也不会改用后面的规则。禁用规则不参与执行。拖动卡片正文可调整顺序，跨过相邻卡片时保存新顺序。

## 理解预览

| 位置 | 统计口径 |
|---|---|
| 规则卡片的会话数量 | 在运行中或近 30 分钟活跃的会话里，符合该选择器的对象；禁用规则也可以预览 |
| 条件编辑页预览 | 符合草稿条件的运行中会话，占全部运行中会话的比例 |
| 新建规则旁的会话数量 | 应用启用状态、执行范围和优先级后的计划，包含无法执行时的原因 |
| 状态条分段图 | 以运行中或近 30 分钟活跃的去重会话为总数，分成可停止、可继续和不受影响；无法执行的动作计入不受影响 |

预览反映最近读到的状态，实际执行时会再次检查。环内「周用量」的百分比沿用剩余额度口径；例如 83% 表示剩余 83%。图注中的规则数包含禁用规则。

## 两种动作

**停止会话**：向 Codex 发送用户停止请求，并请求暂停自动续跑目标。会话历史、文件和排队消息保留。与之不同，状态面板的「停止监听」只取消 AlmostReset 的等待。

**调整后继续**：必要时中断正在执行的工作，应用所选模型、推理强度和速度，检查设置后发送提示词。未指定的项目保持当前配置。默认提示词为中文「继续」或英文 `continue`。可用配置取决于当前账号的模型目录，不支持的组合会显示失败原因。

模型设置不会改变已经生成的内容。发送提示词会启动后续工作并可能消耗额度；遇到无法确认的发送结果，应用不会自动重发。

## 连接与兼容性

用量和已保存会话通过本机 Codex CLI 的 App Server 读取，认证由 Codex 已有登录处理。设置页自动寻找 CLI 并显示实际路径，只有自动检测失败或需要指定版本时才需要手动选择。

桌面端会话控制使用 Codex 私有、带版本号的本地 IPC 协议。保持桌面端运行；协议变化可能使控制暂时失效。桥接不可用时，仍可能读取用量和会话，但修改操作会受限。子代理由其父会话管理。

应用不会修改 Codex 状态数据库或全局模型配置，也不会接管其他进程的会话。核心还支持明确配置的共享 App Server socket，控制范围限于该服务已加载的会话。

## 本地数据

规则、会话 ID、继续提示词、重置检查点和最多 500 条简要活动记录保存在：

```text
~/Library/Application Support/AlmostReset/state.json
```

活动记录可能包含会话标题和错误信息，但不保存完整对话或登录凭据。语言、CLI 路径和检查间隔等偏好使用 macOS 用户设置。更新应用保留这些数据；读取状态失败不会覆盖原文件。

应用会先保存重置事件与执行计划，再发送命令。保存检查点失败时不执行动作；中断的执行保留记录，不自动重放。

## 安装与校验

发布包需要 macOS 14+ 和 Apple Silicon，采用本地临时签名，尚未经过 Apple 公证。首次打开遇到拦截时，请确认来源并参考 [Apple 的应用打开说明](https://support.apple.com/zh-cn/102445)。

将 DMG 和同一 Release 的校验文件放在同一目录后执行：

```bash
shasum -a 256 -c AlmostReset-0.7.4-macOS-arm64.dmg.sha256
```

退出旧版后替换应用即可更新。不要在正在执行规则时替换应用。重新打开后，确认连接和预览，再按需启动下一轮监听。
